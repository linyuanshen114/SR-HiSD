# 逐级 LBSD 终点：双侧梯度流

此任务依赖逐级 BCC→HEX LBSD 搜索任务 1490068 的结束。任务 1490193
使用 Slurm `afterany:1490068`；在依赖等待时不占用计算节点。源任务结束后，
选择器只接受已保存、力 RMS 不大于 1e-7、按原 mean-zero Hessian 的 ±1e-7
零带冷暖低谱通过的一阶候选；如果不存在，写出 blocked 状态并停止，不会把失败
候选当过渡态。

实算使用与直接 1-LBSD 双侧流程相同的冻结 GF 数值核与参数：归一真实最负谱方向
两侧扰动 ±1e-5，半隐式梯度流 dt=1，完整力 RMS 阈值 1e-9，单侧上限 200000
更新。每步保存力 RMS、最大点残差和耗时，每100步写能量，每2000步保存 checkpoint；
正负两侧分别保存初值、完整历史、端点场、力、能量、相型证据与计算开销。方向在
原始 HVP 下重新验证负特征值和残差，且结果不自动声称端点是 Hessian 认证极小值。

一侧发生启动、数值或输出异常时，记录失败并仍尝试另一侧；两侧数值使用相同 GF 核。
每侧使用真实 BCC 和 HEX 参考输出保守相型证据，未匹配时明确记 unknown。
参数和 frozen 引擎与直接路线保持一致；仅逐级冻结副本额外增加逐侧异常隔离。

selector 合成测试覆盖未解、非一阶、源文件缺失、截断 JSON、越界路径与力未达标；
计算节点预检 1490188 对 N=8 真实 GF 与原核五步逐位一致，并验证第一侧人为失败时
仍执行第二侧。source status、候选和暖谱文件的 SHA256 见任务启动后的
`results/source_selection.json`；每侧结果及完整日志位于 `results/flow` 和 `logs`。
输出中的时钟为 GF 准备、每侧求解、端点审计、总墙钟，不计入原 LBSD 搜索计时。
所有方法使用 4 个物理核、16 GB 内存的共享节点；逐级 GF 使用 c03，直接路线使用 c01。
